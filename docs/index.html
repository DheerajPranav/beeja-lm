What Beeja is

Beeja means seed. It starts as random noise and learns, one token at a time, to predict what comes next. The point isn't a big model — it's to build and understand every mechanism a modern language model is made of, transparently enough to test and explain each one.

Built by hand

Embeddings, causal self-attention, MLP, residual blocks, normalization, and generation are written from raw tensor ops — no prebuilt GPT class.

Tested, not claimed

Every component has a focused test: attention shapes, no-future-leakage, tiny-batch overfit, checkpoint round-trips, tokenizer round-trips.

Honest by design

Every number here is measured on the hardware below. Nothing is fabricated; results on a tiny corpus are labelled as such.

The mechanism at the core

Causal self-attention lets each position read from every earlier position — and the mask is what keeps prediction honest (no peeking ahead). It's implemented explicitly, not via a fused kernel.

Attention(Q, K, V) = softmax( (Q Kᵀ / √d_k) + causal_mask ) V # the mask sets every future key to −∞ *before* softmax, so its probability is exactly 0 # verified end-to-end: perturbing token t leaves all logits before t bit-for-bit unchanged

Trained on next-token cross-entropy:

L = −(1/T) · Σₜ log p(xₜ | x<ₜ)

Where it runs

Local development

Apple Silicon M2, 8 GB unified memory · PyTorch 2.13 with the MPS backend · Python 3.13. Local defaults are kept small and safe; only smoke tests run automatically.
