# Stage Report Template

## Stage

Name and status: complete, partially complete, or blocked.

## Implemented

List the meaningful behavior delivered, not every minor edit.

## Files changed

List paths and their purpose.

## Verification

```text
<command>
<actual concise result>
```

## Learning notes

Explain the key concept, equation, and important tensor shapes.

## Resource safety

State whether only smoke tests ran. List any full-training command prepared but not executed.

## Remaining risks

List unresolved correctness, performance, data, or environment concerns.

## Next command

Give exactly one recommended skill command.
